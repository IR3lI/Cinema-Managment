NGINX Web Server (Static & SPA)

NGINX trả trực tiếp file HTML/CSS/JS từ thư mục root mà không cần thông qua Backend.

root .../nginx/html; index index.html; try_files $uri $uri/ /index.html;
Thử đổi URL không có file vật lý

Upstream Load Balancing (2 Node Backend)

Cân bằng tải Round-Robin giữa Node 1 (5001) và Node 2 (5002).

upstream cine_backend { server 127.0.0.1:5001; server 127.0.0.1:5002; }

Cấu hình Container (Docker Network)

Trong Docker Compose, NGINX proxy tới service name thay vì localhost:

upstream cine_cluster { server backend_1:5000; server backend_2:5000; } proxy_pass http://cine_cluster;
Tệp cấu hình sẵn sàng: docker-compose.buoi8.yml

Tên Miền Giả Lập & HTTPS Tự Ký

Đã tạo chứng chỉ SSL cinemanet.crt và cấu hình Domain cinemanet.local.

File hosts: 127.0.0.1 cinemanet.local
Truy cập https://cinemanet.local 🔒
Vì sao trình duyệt báo "Not Secure"?
Chứng chỉ do ta tự ký (self-signed) không nằm trong chuỗi tin cậy (Chain of Trust / Trust Store) của Hệ điều hành. Trên Production, sử dụng Certbot (Let's Encrypt) để được tự động tin cậy miễn phí.
